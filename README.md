# Health Tracker (PWA)

Installable, offline home-screen web app: weight tracker, food log, calorie deficit (Mifflin-St Jeor), peptide dose log and schedule, syringe calculator, health log.

Plain HTML/CSS/JS, no build step. All personal data is stored only in the browser's localStorage on the device. The app ships a built-in list of common foods and a built-in list of common peptides, both with typical reference values (not personal). Peptide reference doses are labelled as general information, not medical advice, and stay editable. Load a personal data file with **More → Import data**.
